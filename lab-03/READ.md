Laboratorio 03: EDA

Este reposotorio contiene un pipeline de análisis de datos enfocado en la detección de anomalias de calidad, exploración visual y tabla del cohorte solicitado.

Analiza los datos provenientes de una cohorte de pacientes de datos de Synthea (descargados).
EDA: El análisis de los datos usando una cohorte de interes, en este caso pacientes con diabetes.
Resultados clave:
- Figura multipanel 2x2 para publicación del análisis de la cohorte.
- Tabla de caracteristicas basales de la cohorte.
- Evaluación de herramientas matplotlib, seaborn y plotly.

Cómo se corre

Requisitos:
Python 3.0 instalado. 
Dependencias necesarias: pandas, matplotlib, seaborn, plotly, numpy.
Archivos necesarios encounters.csv, observations.csv y patients.csv del repositorio de synthea: https://synthea.mitre.org/downloads, proporcionados en este reposotorio.
